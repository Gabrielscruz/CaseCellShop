## ⚡ Guia Rápido de Execução

Se você deseja iniciar todo o ecossistema com um único comando:

```bash
# Na raiz do repositório
docker compose up --build -d
```

### URLs e Portas Ativas:
* **API Backend:** [http://localhost:3000](http://localhost:3000)
* **Documentação OpenAPI / Swagger:** [http://localhost:3000/api/docs](http://localhost:3000/api/docs)
* **Dashboards Grafana:** [http://localhost:3001](http://localhost:3001) *(login: `admin` / senha: `admin`)*
* **Prometheus Metrics:** [http://localhost:9090](http://localhost:9090)
* **RabbitMQ Management:** [http://localhost:15672](http://localhost:15672) *(login: `casecellshop` / senha: `casecellshop_pwd`)*
* **Prisma Studio (Visualizador de Banco):** [http://localhost:5555](http://localhost:5555) *(iniciado com `cd app && npx prisma studio`)*
