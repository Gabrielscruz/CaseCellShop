# 📑 Especificação Completa da API REST (OpenAPI / Swagger)

Este documento contém o scraping e a documentação completa dos endpoints da API do **CaseCellShop**, gerados a partir da especificação OpenAPI 3.0 (`http://localhost:3000/api/docs`).

---

## 1. Interface Interativa Swagger UI

A especificação OpenAPI 3.0 é servida interativamente pelo NestJS na rota **`/api/docs`**:

* **URL de Acesso:** [http://localhost:3000/api/docs](http://localhost:3000/api/docs)
* **Recursos Disponíveis:**
  - Teste interativo direto no navegador via botão **"Try it out"**.
  - Schemas tipados de Request Body (`CreateOrderDto`, `OrderItemDto`) e Response Body.
  - Documentação de cabeçalhos de controle (`x-idempotency-key`, `x-correlation-id`).

## 3. Detalhamento dos Endpoints

### 3.1. `GET /products`
Retorna a listagem de capinhas e acessórios com paginação por cursor e cabeçalho indicador de cache.

#### Parâmetros de Query
| Parâmetro | Tipo | Obrigatório | Padrão | Limites | Descrição |
| :--- | :---: | :---: | :---: | :---: | :--- |
| `limit` | integer | Não | `1000` | Min 1, Max 1000 | Quantidade de itens por página. |
| `cursor`| string | Não | `null` | Base64URL | Cursor opaco apontando para o último item da página anterior. |

#### Exemplo de Chamada cURL
```bash
curl -i "http://localhost:3000/products?limit=2"
```

### 2.2. `POST /checkout`
Inicia a compra de forma assíncrona. Efetua a baixa atômica de estoque no PostgreSQL, grava a chave de idempotência no Redis e publica o evento de faturamento no RabbitMQ.

#### Cabeçalhos HTTP
* `Content-Type: application/json` (Obrigatório)
* `x-idempotency-key: string` (Opcional, recomendado para prevenção de duplicidade)
* `x-correlation-id: string` (Opcional, para rastreabilidade de ponta a ponta)

#### Corpo da Requisição (JSON)
```json
{
  "customerId": "c0eebc99-9c0b-4ef8-bb6d-6bb9bd380a33",
  "items": [
    {
      "productId": "ff93c473-4815-464e-82c6-c5efa7218684",
      "quantity": 1
    }
  ]
}
```

#### Resposta Real Scrapeada (`HTTP 202 Accepted`)
```http
HTTP/1.1 202 Accepted
content-type: application/json; charset=utf-8
x-correlation-id: 9a8ef32b-4567-4e12-8567-cba987654321
```
```json
{
  "orderId": "c3dd4a2b-e908-40cf-88c4-ce3d2ad54bc2",
  "status": "ACCEPTED"
}
```

### 2.3. `GET /orders/{id}/status`
Consulta a situação atual do pedido na esteira de processamento assíncrono.

#### Parâmetros de Path
* `id` (UUID v4): Identificador do pedido retornado no checkout.

#### Exemplo de Chamada cURL
```bash
curl http://localhost:3000/orders/c3dd4a2b-e908-40cf-88c4-ce3d2ad54bc2/status
```

#### Resposta Real Scrapeada (`HTTP 200 OK`)
```json
{
  "orderId": "c3dd4a2b-e908-40cf-88c4-ce3d2ad54bc2",
  "status": "ACCEPTED",
  "totalAmount": 50.8,
  "createdAt": "2026-09-25T03:07:21.495Z",
  "updatedAt": "2026-09-25T03:07:21.495Z"
}
```

## 3. Catálogo Real de Erros HTTP Desacoplados

Todas as respostas de erro seguem o contrato padronizado emitido pelo [`GlobalExceptionFilter`](file:///home/gabriel/Documentos/CaseCellShop/app/src/common/filters/global-exception.filter.ts):

### 3.1. Erro de Validação de Dados (`HTTP 400 Bad Request`)
Disparado pelo `ValidationPipe` quando parâmetros são inválidos ou omissos:
```json
{
  "statusCode": 400,
  "error": "Bad Request",
  "message": [
    "items.0.productId must be a valid UUID v4."
  ],
  "correlationId": "test-err-scrape-123",
  "timestamp": "2026-09-25T03:07:57.472Z",
  "path": "/checkout"
}
```

### 3.2. Produto Não Encontrado (`HTTP 404 Not Found`)
Disparado quando o item solicitado não existe no banco de dados (`ProductNotFoundError`):
```json
{
  "statusCode": 404,
  "error": "Not Found",
  "message": "Product with ID \"11111111-1111-4111-8111-111111111111\" not found in catalog.",
  "correlationId": "test-err-notfound-123",
  "timestamp": "2026-09-25T03:08:09.735Z",
  "path": "/checkout"
}
```

### 3.3. Conflito por Falta de Estoque (`HTTP 409 Conflict`)
Disparado quando a quantidade solicitada excede o saldo físico no banco (`InsufficientStockError`):
```json
{
  "statusCode": 409,
  "error": "Conflict",
  "message": "Insufficient stock for product \"a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11\". Transaction cancelled.",
  "correlationId": "test-err-stockout-123",
  "timestamp": "2026-09-25T03:08:20.483Z",
  "path": "/checkout"
}
```

### 3.4. Transação em Processamento Concorrente (`HTTP 409 Conflict`)
Disparado quando um retry chega enquanto a transação anterior ainda está rodando (`TransactionInProgressError`):
```json
{
  "statusCode": 409,
  "error": "Conflict",
  "message": "Transaction is already being processed. Please wait a moment.",
  "correlationId": "retry-conflict-456",
  "timestamp": "2026-09-25T03:08:30.123Z",
  "path": "/checkout"
}
```
